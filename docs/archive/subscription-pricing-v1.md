# 订阅定价与套餐设计 v1

> 状态：首期单档方案已确认并部署；2026-10-14。
> 约束：[领域语言](../../CONTEXT.md#个人订阅托管模式)、[改造计划](../hosted-personal-subscription-development-plan.md)、[运行手册](../runbooks/hosted-personal-subscription.md)。
> 本文是产品决策记录；套餐的工程契约以 `PlanVersionSchema` 为准，运营套餐文件不进仓库（`deploy/hosted/operator/` 已 gitignore）。

## 1. 定价立场

luoome 卖的不是行情数据（同花顺免费就有），而是**纪律系统 + 主动提醒 + 可信的 AI 建议**：

> Strategy 版本化 → 信号 → T+1/T+3/T+5 真实观察 → 带反证和风险的 Advice → 成交关联 → 复盘校准

两条定价纪律：

1. 套餐版本化冻结（PlanVersion），老用户续期按原服务期结算，不随新套餐漂移——已是领域契约，购买页必须兑现。
2. 定价页与宣传文案绝不出现"荐股""收益""胜率承诺"。卖的是工具和数据，不是"带你赚钱"；
   这既是合规矩线（无投顾资质），也是品牌资产。

## 2. 市场锚点

| 产品 | 价格 | 折算月价 |
|---|---|---|
| 同花顺 AI 问财 | 299 元/年 | ≈25 元/月 |
| 指南针 AI 选股 | 998 元/年 | ≈83 元/月 |
| 同花顺 Level-2 / 专业投顾会员 | 几十～几百 元/月 | — |
| 财富趋势量化策略（机构向） | 1.5 万元/年 | 非目标用户 |

定位：比免费工具专业、比投顾服务便宜一个数量级。49 元/月卡在问财与指南针之间。

## 3. 首期方案：单档 49 元/月

邀请期只上一个版本化月度套餐，降低决策成本；首要目标是验证"试用 → 付费 → 续费"转化，
不是榨取价格梯度。年付折扣与多档拆分留到有真实成本和转化数据之后（见 §6）。

### 3.1 套餐内容

核心订阅包含（价值锚点，全部保留）：

| 功能 | 理由 |
|---|---|
| Watchlist + AlertPlan + WatchTrigger 预警通知 | "不用盯盘，有事叫我"是付费第一动机 |
| Strategy 全套（版本/发布/调度运行/信号/观察） | 差异化核心：可验证的策略事实链 |
| 报告（开盘简报/收盘复盘/周报） | 每日触达，养成习惯，是续费理由 |
| 持仓/账户/逐股交易计划（TradingPlan） | 让建议落到"我的账户该怎么做" |
| 决策复盘 + confidence 校准 | 独有信任机制：建议历史准不准有数字可查 |
| AI 建议（个股/持仓/市场观点，含反证、风险、有效期） | 溢价来源；额度制，见 §5 |
| 行情数据（东财/腾讯/新浪链路） | 零边际成本、用户无替代，开箱即用 |
| 数据导出、到期后历史读取窗口 | 已有工程契约（7 天试用、30 天读取），写进购买页 |

### 3.2 不包含 / 缓做

| 功能 | 处理 | 理由 |
|---|---|---|
| 远程 MCP、团队组织、多账户、新市场 | 不做 | 改造计划已排除；个人订阅单默认账户 |
| 券商适配、自动下单 | 永不做 | advice ≠ trade，trade 硬卡是架构与合规红线 |
| 基本面 PIT 评分（FinancialFact/FundamentalScore） | 缓做 | 仅 mock，gate=not-ready，未过真实数据门禁不得开放 |
| 持仓 CSV 批量导入、本地整库迁云 | 缓做 | 独立设计，不影响手工持仓主流程 |
| Research Vault Git 远程同步 | 降级 | 极客向小众功能；托管版保留受管研究文件 |
| 龙虎榜、连板天梯、北向资金、A股情绪 | 二期高档 | 衍生数据，非核心链路，适合做档次区隔 |
| 单机 CLI/TUI/MCP | 保持免费 + BYOK | 开源获客漏斗与隐私卖点，不算订阅内容 |

### 3.3 首期运营套餐文件

```json
{
  "id": "personal-monthly-2026-10",
  "code": "personal-monthly",
  "currency": "CNY",
  "priceMinor": 4900,
  "durationMonths": 1,
  "productPolicyVersion": "hosted-web-v2",
  "publishedAt": "2026-10-14T00:00:00Z",
  "limits": {
    "watchlistStocks": 100,
    "enabledRules": 20,
    "dailyJobs": 20,
    "concurrentJobs": 1,
    "queuedJobs": 10,
    "researchUnits": 30
  }
}
```

额度口径（执行点：`packages/tools/src/hosted/invoke.ts`、`packages/db/src/hosted/platform-repositories.ts`）：

- `watchlistStocks`：自选成员总数上限；100 只覆盖个人研究半径。
- `enabledRules`：同时启用的预警规则数；20 条对单账户充足。
- `dailyJobs` / `queuedJobs`：每日后台任务与排队上限；支撑每日调度 + 报告 + 观察补全。
- `researchUnits`：研究任务预占单位，与 `HOSTED_JOB_BUDGET_MICRO` 共同约束 AI/长任务成本。
- 额度基准沿用 fixture 套餐数值，邀请期用真实负载校准后再调。

## 4. 试用与续费

- 首次注册授予一次 7 天试用（现有工程契约）；试用即引用本套餐版本。
- 按次购买服务期，不自动扣款；续期由用户主动购买（现有契约，保留）。
- 到期保留 30 天历史读取、导出与删除；历史读取不隐式启动模型或刷新任务。
- 购买页只承诺已装配、已验收的能力；AI 未装配时明确显示不可用，不返回 mock。

## 5. AI 与数据源归属

**数据源：行情必须包含，付费源后续按成本包含。**

- 行情默认链路（东财/腾讯/新浪）无密钥、零边际成本，散户没有"自己的行情源"——包含是卖点。
- Tushare/扶摇等需 token 的源保留为可选 BYO 增强（现有架构已支持），面向专业用户。
- 真实基本面 PIT 数据未来接入时是真实供应商成本，届时核算进高档或单独数据包。

**AI：订阅内含额度制为主，BYOK 为高级选项，双轨并行。**

| 场景 | 模式 | 理由 |
|---|---|---|
| 托管 Web 订阅用户 | 平台统一模型（Kimi/DeepSeek preset），按档给固定 AI 额度 | 目标用户非开发者，配 key 会卡死转化；用量结构天然可控（每日复盘 1 次、策略推荐每候选最多 2 次请求） |
| 超额 | 排队或降级规则兜底（已有 fallback 机制）；不卖无限 AI | 保留 AI 入口 ≠ 提供无限 AI |
| BYOK 选项 | 用户填自己的 OpenAI-compatible key，额度大幅提升（成本自担） | 服务已有 key 的进阶用户；成本控制安全阀；`LUOOME_AI_CONFIG` 架构天然支持 |
| 单机 CLI/TUI/MCP | 永远 BYOK、永远免费 | 获客漏斗与隐私卖点 |

成本侧已有 `HostedJob` 预算、用户用量流水、provider cost attempt 三层计量；
邀请期用真实数据回答"49 元能否包住平均 AI 成本"，再决定二期价差。
当前 `HOSTED_AI_ENABLED=false`，真实模型接入与预算是上线门禁，不在本次部署范围。

## 6. 二期候选（有数据后再决策）

| 档 | 候选价 | 内容 |
